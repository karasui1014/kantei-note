# 元素材

- `chara_src.png` — アイコンの元絵（2048px）。ローファイ探偵のちびキャラが、口を開けて「わぁ！」と驚く表情の絵（もとは職業適性アプリ用に作ったもの）。同じ絵の中に描かれている虫眼鏡も使う

`python3 tools/make_chara_icons.py` を実行すると、ここからキャラと虫眼鏡を切り抜き（`chara.png` / `mag.png`）、
ペンを消して虫眼鏡を握らせ、顔の横に掲げた絵に組み直して、`assets/icons/` のアイコンとファビコンを書き出す。
途中の画像（`chara.png` `mag.png` `icon_master.png`）は毎回作り直すので、git には入れていない。

レンズの位置・大きさ・倍率は、スクリプト冒頭の `LENS` `GRIP` `GLASS_R` `ZOOM` で変えられる。
**顔と眼鏡にかからないこと**（カラスイさんの指定）。
