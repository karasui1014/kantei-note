# AI鑑定ノート

写真から、相場とメルカリの手取りがわかる無料ツール。

品物の写真を、ふだん使っている AI（ChatGPT・Gemini・Claude）に見てもらい、返ってきた答えを貼り付けると、
**相場・メルカリの出品価格と手取り・仕入れの利益・ほかの売り方との比較・出品文のたたき台**がそろった鑑定結果になる。
骨董・工芸・作品なら、作家・年代・技法の見立ても出す。鑑定した品物は記録として残り、相場の合計や売れた実績が見られる。

- 静的PWA（ビルドなし）。サーバー・ログイン・APIキーなし
- 写真も記録も端末の中だけ（記録は localStorage、写真は IndexedDB）。このツールからは何も送信しない
- AIとは「コピペ連携」でつなぐ。写真と指示文をAIアプリに渡し、答えを貼り戻す

## 使い方（3つ）

1. **写真を選ぶ** … 全体と、ラベル・型番・刻印のアップ。4枚まで。「わかっていること」「状態」「仕入れ値」は任意
2. **AIアプリに送る** … スマホは共有ボタンで写真と指示文をまとめて渡す（指示文はクリップボードにも入る）。パソコンは指示文をコピーして、写真はドラッグ＆ドロップ
3. **答えを貼り付ける** … AIの答え全体でも、最後の `json` の枠だけでもよい

AIを使わずに、自分で調べた金額を入れて記録することもできる（「AIを使わずに、自分で金額を入れる」）。

## 精度について

メルカリには公式の価格APIがなく、売り切れ価格を自動で集めるのは規約上できない。そのため、

- AIの見立て（写真と情報から品名と相場を推定。AIアプリのウェブ検索も使ってもらう）
- 実際に売れた値段を確かめるリンク（メルカリ売り切れ・Yahoo!オークション落札相場・ラクマ・Yahoo!フリマ・eBay・Google）
- 見つけた売り切れ価格を入れると、中央値で相場を補正して、そのまま出品価格にできる

の3つを組み合わせている。

## ファイル

```
index.html            画面の土台。はじめての人向けの説明（検索エンジンにも読ませる）もここ
assets/data.js        手数料・送料・検索リンク・AIへの指示文・文言  ← 料金が変わったらここだけ直す
assets/core.js        計算と読み取り（指示文づくり、AIの答えの読み取り、手取り・利益の計算）
assets/store.js       保存（localStorage・IndexedDB・写真の縮小・書き出しと読み込み）
assets/app.js         画面
assets/style.css      見た目
assets/icons/         アイコン・ファビコン（tools/make_chara_icons.py で作り直せる。元絵は .source/）
assets/og.jpg         SNSで共有されたときの画像
manifest.webmanifest  ホーム画面に追加したときの設定
sw.js                 オフライン用（ネットワーク優先）
tests/run.js          テスト
tools/make_chara_icons.py  アイコンを作るスクリプト（ローファイ探偵が虫眼鏡で鑑定している絵。顔は隠さない）
tools/make_icons.py   SNS共有画像（og.jpg）を作るスクリプト
```

## 手元で確かめる

「ローカルで確認.command」をダブルクリック（http://localhost:8962 が開く）。
`localhost` では Service Worker を登録しない（古いキャッシュが出る事故を防ぐため）。

> スマホの共有ボタン（写真と指示文をまとめて AI アプリに渡す機能）は **HTTPS でしか動かない**。
> Mac の IP アドレスで開いたスマホでは、「指示文をコピー」の流れになる。共有の動作は公開してから確かめる。

## テスト

```bash
node tests/run.js
```

AIの答えの読み取り（崩れたJSON・文章だけの答え・指示文を貼ってしまった場合など）、手数料と送料の計算、
画面のHTMLに `undefined` や `NaN` が混ざらないか、文字色のコントラスト（4.5:1以上）、言葉づかい（禁止語）、
ファイルのそろいを確かめる。**文言・料金・読み取りを直したら必ず走らせる。**

## 料金を直すとき

1. `assets/data.js` の `SHIP`（送料）や `PLATFORMS`（手数料）を直す
2. 同じファイルの `FEES_AS_OF`（いつ時点の料金か）を更新する
3. `sw.js` の `CACHE` の版を上げる（上げないと、古い料金のまま表示され続ける）
4. `node tests/run.js`

2026年9月時点で確かめた値：メルカリ販売手数料10%（1円未満切り捨て）、Yahoo!フリマ5%、ラクマ10%（実績で最大4.5%）、
Yahoo!オークション10%（LYPプレミアム8.8%）。送料はメルカリ公式の送料一覧（2026年1〜2月更新）に合わせてある。

## 公開（GitHub Pages）

`index.html` の canonical・OGP・JSON-LD は **`https://karasui1014.github.io/kantei-note/`** を前提にしている。
リポジトリ名を変えるときは、この URL（index.html の中に4か所）と sitemap.xml も直すこと。
公開したら、Google Search Console に URL プレフィックスで登録し、sitemap.xml を送ると検索に載りやすい。

## デザインの方針

**静かで、余白があって、線が細い。** 太字・グラデーション・光る影に頼らず、階層は文字の大きさとわずかな明度差でつくる。

- 地は温かい紙の色、文字は墨、色は朱の一色だけ。朱を置くのは「押すところ」と「手元に残る額」だけ
- 品名と見出しは明朝、数字は等幅の数字（tabular-nums）
- 枠線は `--hair`（地に薄く重ねた線）、影は薄いものを重ねる
- 文字と地のコントラストは 4.5:1 以上（ライト・ダークとも tests で実測）

## 言葉づかいの約束

- 使う人や品物を否定しない。「売れない」「価値がない」「赤字」は使わず、「利益は小さめ」「まとめ売りにすると動きやすい」のように、次の一手が見える言い方にする
- 機能はそのままの名前で呼ぶ。世界観の比喩は被せない
- 入口の負担を増やさない。必須は「写真か、品物のメモのどちらか」だけ

## 免責

表示する金額は、AIの見立てと一般的な料金表にもとづく目安。売れる金額を約束するものではない。
メルカリ・Yahoo!オークション・Yahoo!フリマ・ラクマ・eBay・ChatGPT・Gemini・Claude の各サービスとは関係のない、個人制作のツール。
